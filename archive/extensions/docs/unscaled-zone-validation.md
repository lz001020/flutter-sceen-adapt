# UnscaledZone 使用边界与验证记录

## 选择模式

需要点击、拖动等交互的局部反适配组件，推荐显式使用 `full`：

```dart
UnscaledZone(
  mode: UnscaledZoneMode.full,
  child: YourInteractiveWidget(),
)
```

`full` 同时恢复上下文、布局占位和绘制/命中坐标，但仍受父约束和祖先裁剪、命中边界影响。本轮验证不构成任意布局下的兼容保证。

`contextFallback` 是默认模式，保留父布局占位。适合明确需要保留占位、并已检查溢出影响的场景；不应假定整个可见区域都能交互。

两种模式的绘制反适配比例均为 `1 / scale`。例如设计宽度 768、设备原始逻辑宽度约 411.4 时，`scale≈0.536`，80 宽的子组件在适配坐标中绘制约 149.3 宽：

| 模式 | 绘制宽度 | 父布局占位 |
| --- | ---: | ---: |
| normal | 80.0 | 80.0 |
| contextFallback | 149.3 | 80.0 |
| full | 149.3 | 149.3 |

因此 context 的绘制内容可超出原占位。Flutter 祖先命中测试可能在到达子组件前就排除这些位置，产生“看得见、点不到”的区域；本轮已复现这一限制。

## 2026-09-13 Android 模拟器验证

环境：Android 模拟器 `emulator-5554`，设备界面显示 Pixel 10 / API 37；Flutter 3.35.7。测试矩形逻辑尺寸为 80×48。数据来自当日截图及 ADB Flutter 日志。

| 验证内容 | 结果与证据 |
| --- | --- |
| 375、320、768 设计尺寸切换 | normal、context、full 几何测量均符合预期 |
| full 右下角内侧，320 | 21:38:49，局部坐标 (78.5, 47.0)，收到点击 |
| full 右下角内侧，768 | 21:39:25，局部坐标 (77.5, 46.4)，收到点击 |
| full 内部与外部点击 | 22:02 的探针日志中，内部点击 delta=1；右侧、下侧外部点击 inside=false、delta=0 |
| normal 内部与外部点击 | 22:02 的探针日志中，内部响应，外部计数不增加 |
| context，768 | 原占位覆盖的部分可点击；溢出部分多次 inside=true、delta=0；外部点击 delta=0 |

768 下 context 的两个代表记录：

```text
22:02:28 mode=context local=(24.9,14.5) inside=true delta=1
22:02:27 mode=context local=(69.1,27.8) inside=true delta=0
```

这里的 `inside` 指蓝色矩形的可见范围，不代表该位置一定能通过祖先命中检查。`cancel`、拖动和多指记录不作为单击通过证据。

结论：full 在本轮布局、设计尺寸与采样位置下的几何、内部/边缘命中和外部不响应验证通过；context 的溢出命中限制已确认，不标记为全可见区域命中通过。
