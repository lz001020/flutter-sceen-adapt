# 小米 14 锁定竖屏性能复验（2026-10-15）

本报告保留页面参数对齐前的完整批次。测试后完成的公平性修正、Timeline 诊断与最终三轮数据见 [发布前最终复核](performance-final-20261015.md)。下面“待定位”的描述是本批当时状态；不能沿用本批局部更新优势作为最新排名。

## 正式结论

本次固定竖屏后，design_scale 与 ScreenUtil 在复杂信息流的 total p90 中位数几乎相同，局部更新优化组为 design_scale 较低，父级重建优化组仍为 ScreenUtil 较低。不能将先前方向未受控批次中的“三个场景均较慢”推广为库的普遍性能损失；也不能据新批次宣称不存在性能风险。

父级重建仍有可重复的耗时差异，需要后续核对像素级工作量并采集 trace。当前只测量库间、写法间对照，没有本库修改前后的受控版本对照，不能称为已确认“版本性能回退”。

## 测试条件与有效性

- 小米 14 / 23127PN0CC / SM8650 / Android 16；物理显示 1200×2670 / 480dpi；Flutter 3.35.7 / Dart 3.9.2，Profile；ScreenUtil 5.9.3。
- 测试期间将 `accelerometer_rotation=0`、`user_rotation=0`。更新专项每组前后、信息流每组前后均保存有效显示的 `mOverrideDisplayInfo`，不使用面板的 `DisplayDeviceInfo.rotation` 推断应用方向。
- 更新专项 24 组的 48 份快照，以及信息流 6 组的 12 份快照，均确认 rotation 0、有效显示与 app 尺寸 1200×2670。设备旋转设置在结束后恢复为原值 `accelerometer_rotation=1`、`user_rotation=0`，读回核验成功。
- 更新专项两场景 × 四种实现 × 三轮；每组预热 30 次，测量 180 次更新，第二轮反转顺序。24 组全部完成，共 4320 帧、构建次数断言通过，所有组超过 16.667ms 的帧数为 0。
- 复杂信息流两库各三轮，沿用 1000 项共享页面、7 次混合操作、50 次纵向自动滚动；全部取得 `mixedActions=7` 与 `automationComplete=50`。帧数中位数差约 0.36%。
- 此次没有修改页面实现或核心算法，仅增加旋转锁定与逐组方向检查，便于保留相同工作负载。前述测试中默认边框、顶部高度等像素级差异尚未修正，字体栅格化也未逐像素核验；不能归因到适配算法的纯成本。

### 分场景判断

父级优化组：design_scale 的 UI / total p90 中位数高 0.251 / 0.736ms（total 相对 ScreenUtil 约高 17.1%）。三轮 total 都较高；ScreenUtil 第一轮显著快于其后两轮，逐轮数据必须保留，不能只用中位数给出稳定倍率。父级差异未因锁定竖屏消失，仍需定位。

局部优化组：design_scale 的 UI / total p90 中位数低 0.097 / 0.432ms，三轮都较低。但 UI 第三轮只差 0.007ms；小样本、未锁定频率和逐帧调度，不能据此宣称稳定领先。相对于本库动态写法，复用减少了详情 build，但第三轮帧耗时未改善，仍应分开看构建计数与时间。

复杂信息流：total p90 中位数只差 0.003ms，可描述为本批接近，不能当作胜负；第一轮 design_scale 较慢，后两轮接近。total p99 中位数为 8.632 / 7.701ms，design_scale 长尾较高；各轮超过 16.667ms 的帧数分别为 2/3/4 与 2/2/2，不能宣称完全等价或系统零掉帧。

## 与先前结果的关系

[上一批观测报告](performance-conclusion-20261015.md)的有效显示方向首尾不同；本批锁定竖屏后，局部更新和复杂信息流结果改变。不能把前一批简单标为“横屏数据”，因为无法确定旋转发生时刻，也不能把全部变化归因于方向：不同批次的系统负载和调度等没有完全受控。两批数据都保留，本批优先用于竖屏范围判断。

构建机制的结论没有变化：两库父级优化组均跳过静态商品子树；静态详情由每轮动态写法的 1440 次降为 0 次。局部更新价格仍构建 180 次，详情由 180 次降为 0 次。子树复用是通用 Flutter 优化，非 design_scale 独有收益。

vivo 的单轮专项与历史 raster 波动继续保留，尚未关闭。没有 iOS 真机性能数据，也未执行严格 120Hz、内存、功耗或业务体验验收。固定 16.667ms 参考预算不能代表高刷通过；三轮中位数也不构成显著性检验。
