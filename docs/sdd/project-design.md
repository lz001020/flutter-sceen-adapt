# 核心项目设计

本轮范围按用户要求收敛为核心全局适配，所有局部扩展已归档。
当前结构和数据流见 [架构](../architecture.md)，公共契约见 [使用指南](../usage.md)。

| 阶段 | 交付 | 状态 |
| --- | --- | --- |
| S0 | 初步目录迁移 | 已完成 |
| S1 | 配置独立；binding 持有 Controller 和设备读取；根 Scope 合并并借用状态 | 已实现并回归 |
| S2 | 移除 ScreenSizeUtils、旧入口、非目标导出；公共 API 和迁移说明 | 已实现并回归 |
| 扩展归档 | 四类扩展、局部状态、原生注册、混合测试和示例历史 | 已归档 |
| S3 | 独立 benchmark，迁移已有实验，隔离宿主和依赖 | 实现完成，验收见发布清单 |
| S4 | 发布检查、Android 配置清理、设备回归 | 进行中 |

Controller 创建者负责生命周期，业务通过 of/maybeOf/read 获取 binding 的同一实例。
设备输入不属于实例业务 API；内部顶层函数未从主入口导出。独立构造用于测试，不表示支持多窗口。

不引入 Reader、Dispatcher、Handle 或独立渲染层。发布包仅保留核心实现及使用示例。
