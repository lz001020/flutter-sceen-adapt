# 项目路线图

产品定位：Android / iOS 单窗口应用的全局设计稿坐标适配。
2026-10-11 调整：先完成 S1、S2，再归档全部局部扩展，随后推进 S3、S4。

核心保证：计算、配置与启停、binding 渲染/输入、Scope MediaQuery 使用一致快照。
